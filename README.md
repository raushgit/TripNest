# TripNest

Your collaborative travel companion. Create shared trip spaces, log memories in real-time, and explore the world with friends.

## Overview

TripNest is a collaborative travel planning and documentation platform designed to help groups of friends coordinate trips, share experiences, and preserve memories together. Whether you're planning a weekend getaway or a month-long adventure, TripNest makes it easy to stay organized and connected throughout your journey.

## Features

- **Shared Trip Spaces** - Create collaborative trip workspaces where all participants can contribute and stay updated
- **Real-Time Memory Logging** - Capture and share moments instantly as they happen during your travels
- **Collaborative Planning** - Plan activities, accommodations, and itineraries together with your travel companions
- **Friend Integration** - Easily invite friends and manage shared travel experiences

## Tech Stack

- **TypeScript** (96.5%) - Primary language for type-safe development
- **JavaScript** (3%) - Supporting JavaScript code
- **CSS** (0.5%) - Styling

## Getting Started

### Prerequisites

- Node.js and npm installed on your machine
- Git for version control

### Installation

1. Clone the repository:
```bash
git clone https://github.com/raushgit/TripNest.git
cd TripNest
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm start
```
